# TestOnline

Обучающая платформа по финансовой безопасности для школьников и студентов. Урок — слайды или видео, затем тест. Балл сохраняется.

Интерфейс и материалы ведутся на двух языках: русском и казахском. Отдельные приложения не нужны: всё открывается в браузере.

Нужны Node.js 22 и Postgres.

## Запуск

В папке проекта:

```bash
npm run setup
```

Создайте `server/.env` по образцу `server/.env.example` и укажите `POSTGRES_URL`. Затем:

```bash
npm run dev
```

Сайт: http://localhost:5174

`npm run setup` ставит зависимости один раз. Дальше достаточно `npm run dev`.

`npm run dev` поднимает два процесса. В браузере открывают только **5174** — это сайт. Второй процесс слушает порт 3001 и отдаёт API: Vite проксирует на него `/api` и `/socket.io`. Порт 3001 не второй сайт, в браузере его не открывают. В разработке с него не раздаются страницы: корень отвечает 404, работает только API.

В Docker наружу публикуется только Nginx (`HTTP_PORT`, по умолчанию 80). Порт 3001 остаётся внутри сети compose: на него смотрит Nginx.

## Языки

По умолчанию русский. Кнопка «Қаз» / «Рус» в правом верхнем углу переключает язык интерфейса. Выбор хранится в этом браузере (`localStorage`, ключ `lang`: `ru` или `kk`).

На двух языках хранятся и показываются:

- названия уроков;
- названия регионов и организаций;
- слайды, видео и вопросы теста.

Казахская версия урока загружается отдельно от русской. Если казахское поле пустое, на экране остаётся русское. В редакторе урока сохранение требует обе версии: оба названия и оба набора материалов.

Имя человека одно. Его можно написать по-русски или по-казахски, интерфейс его не переводит.

Рядом с языком кнопка «Светлая» / «Тёмная» меняет оформление. Выбор запоминается в этом браузере. Если тему ещё не выбирали, берётся тема системы.

## Кто заходит

| Роль | Куда попадает | Что делает |
| --- | --- | --- |
| Суперглавный | `/admin` | Области, их администраторы, уроки и учебные квизы, запуск квиза любому классу, статистика платформы |
| Администратор региона | `/admin` | Организации своей области, их администраторы, статистика области, запуск учебного квиза любому классу этой области |
| Администратор организации | `/admin` | Классы, тестируемые, запуск учебного квиза только своему классу |
| Тестируемый | `/learn` | Уроки своей группы и живой квиз, если его запустили для его класса |
| Ведущий | `/host` | Свои квизы и публичная комната по QR-коду. Приватный запуск для класса ему недоступен |

Вход общий: `/login`. Первый суперадминистратор создаётся при пустой базе из `SUPER_LOGIN` и `SUPER_PASSWORD`.

Группы, которым назначается урок: 1–4 классы, 5–9 классы, 10–11 классы, студенты. Тестируемый видит уроки своей группы.

## Как это работает

Сайт в браузере не хранит данные. Страницы читают и пишут только через `/api`. Сервер проверяет роль и отдаёт JSON. Картинки и видео урока тоже идут через API: сначала проверка прав, потом файл.

Код разделён так:

| Слой | Где | За что отвечает |
| --- | --- | --- |
| Страницы | `client` | Экраны, язык, тема. Не решают, кому что можно |
| Маршруты | `server/src/index.js` | Вход, cookie, разбор запроса, ответ |
| Правила людей и уроков | `server/src/admin.js`, `server/src/lessons.js` | Кто видит регион, класс, урок, кому можно открыть комнату |
| Правила квиза | `server/src/domain.js` | Длина текстов, число вопросов, формула очков. Базы здесь нет |
| Комната | `server/src/rooms.js` | Лобби, таймер, ответы, итог |
| База | `server/src/db.js` | Postgres: люди, уроки, квизы, результаты, снимок комнаты |

Экран ведущего и экран участника опрашивают сервер раз в секунду. Таймер вопроса живёт в памяти процесса. Снимок комнаты пишется в Postgres, чтобы после перезапуска комната нашлась, но отсчёт заново не ставится, пока процесс не поднимет его сам. Поэтому живые комнаты рассчитаны на один экземпляр приложения.

### Дерево

Суперглавный заводит область. В интерфейсе этот раздел называется «Регионы». У области есть администратор региона. Он заводит организации и их администраторов. Администратор организации заводит классы и тестируемых.

Класс принадлежит одной из четырёх групп: 1–4, 5–9, 10–11 или студенты. У школьного класса есть параллель и название (`5а`). У студентов параллели нет: вместо неё направление.

Районы появляются только у области, в названии которой узнаётся Мангистау. Это пять районов и города Актау и Жанаозен. У такой области организацию без района создать нельзя. У остальных областей района нет, организация привязана сразу к области.

Область удаляется, только если в ней нет организаций и администраторов региона. Класс удаляется, только если в нём нет тестируемых. Организация удаляется вместе со своими классами, тестируемыми и администраторами.

### Урок

Урок создаёт только суперглавный. Это общая программа, не материал школы.

Урок назначается группам, не отдельному классу. Тестируемый 5 класса видит уроки группы «5–9», студент — уроки группы «студенты». Чужую группу сервер не отдаёт, в том числе файл слайда и видео.

Формат один на обе языковые версии: либо слайды, либо видео. Казахская версия хранится рядом с русской. На экране берётся язык интерфейса. Если казахского набора нет, показывается русский.

Тест урока проверяет сервер. Клиенту правильный индекс до отправки не приходит. Ответ — номер варианта. Балл попытки — число верных ответов, не очки за скорость. Если вариант не выбран, балл за вопрос не начисляется. В списке частых ошибок такой вопрос не появляется: туда попадает только выбранный неверный вариант.

`LESSON_MAX_ATTEMPTS` ограничивает число отправок одного человека по одному уроку. После последней попытки урок показывает сохранённый результат.

### Квиз

Квиз — набор вопросов с таймером. Очки за скорость считает сервер, формула и пределы — в разделе «Живой квиз». Правильный вариант на телефон не уходит, пока вопрос не закрыт.

Есть два вида квизов, и они не смешиваются.

Учебный квиз принадлежит суперглавному. Его создают в «Материалы → Квизы». Его запускают суперглавный, администратор региона и администратор организации. Ведущий эти квизы в своём списке не видит и запустить их не может.

Личный квиз принадлежит ведущему. Его видит и запускает только он, публичной комнатой. Администраторы личный квиз классу не отдают.

В форме запуска два режима: «Публичный» и «Приватный».

Публичный: код и QR, участник пишет имя и входит до старта. Так запускает ведущий свои квизы. Так же может суперглавный свой учебный квиз. Регион и организация публичную комнату создать не могут.

Приватный: заранее выбраны организация и класс. Войти может только тестируемый этого класса, уже вошедший под своим логином. Имя берётся из профиля, чужое имя ввести нельзя. Один человек — одно место. На `/learn` такая комната появляется сама, пока она в лобби или идёт: страница проверяет это каждые 3 секунды. После старта новый человек уже не садится.

Куда можно запустить приватную комнату:

| Кто | Куда |
| --- | --- |
| Суперглавный | Любая организация, любой её класс |
| Администратор региона | Любая организация своей области |
| Администратор организации | Только своя организация. Если она одна, список организаций не показывается |
| Ведущий | Никуда: запрос класса сервер отклоняет |

Итог комнаты пишется владельцу квиза, не тому, кто нажал «Запустить». Запуск учебного квиза регионом или школой виден суперглавному. Запуск личного квиза виден ведущему в его истории.

### Статистика

Обзор на `/admin` — это состав: сколько областей, организаций, классов, людей. Графики суперглавного подписаны «по областям». Результатов тестов на обзоре нет.

Результаты читает страница `/admin/stats`. У суперглавного она открывается списком областей. Внутри области — те же четыре карточки, что видит администратор этой области: районы, организации, уроки и квизы. Попытки и ошибки считаются по тестируемым этой области. Публичный квиз без организации в область не входит.

В таблице районов «Верных ответов» — доля верных ответов в тестах уроков у тестируемых этого района. Рядом диаграмма по тем же долям. Пустой ответ в долю не входит. Публичный квиз к району не привязан и сюда не попадает.

На карточке квизов два блока в одном списке. «Публичные» — запуски без района: квиз открывается списком участников. Приватный запуск пишется классу и раскрывается по группам 1–4, 5–9, 10–11 и студентам, затем по квизу, району и организации. Внутри организации — участники, число запусков и верных ответов. Публичный квиз без организации в область не входит, поэтому в статистике области у него нули.

По урокам и квизам колонка «Верных ответов» — сумма выбранных правильных вариантов, не средний балл и не очки квиза. Пустой ответ в эту сумму не входит.

«Чаще всего ошибаются» собирает вопросы, где человек выбрал неверный вариант. Молчание ошибкой не считается. Строка показывает текст вопроса, урок или квиз, число ошибок и число верных ответов по этому вопросу. Список отсортирован по числу ошибок.

Урок сверяется с тем языковым набором, на котором человек проходил тест. Квиз берёт отметку «верно», которую сервер записал в ответ игрока.

История ведущего на `/host` — другое: там по-прежнему очки за скорость и средний балл запуска. Это экран личного квиза, не платформенная статистика.

## Урок

Урок — презентация из слайдов или видео, плюс тест. Русская и казахская версии лежат рядом: свои слайды, своё видео и свои вопросы.

Картинки слайдов и видео хранятся в `MEDIA_DIR` (по умолчанию `server/data/media`). Картинки — в подпапке `files`. Русское видео урока и казахское — разные файлы. Папку нужно включать в резервную копию вместе с базой.

`LESSON_MAX_ATTEMPTS` — сколько раз тестируемый может отправить тест по одному уроку, по умолчанию 1. После последней попытки урок показывает сохранённый результат.

## Тестируемые списком

На странице тестируемых администратор организации загружает `.xlsx`. Столбцы: «Класс», «Имя», «Логин», «Пароль». Имя одно: его можно написать по-русски или по-казахски.

Класс указывается по названию (`5а`) или вместе с параллелью (`5а · 5 класс`), если одно название есть в нескольких параллелях. Пустой пароль создаётся автоматически. После загрузки показывается таблица с логинами и паролями и кнопка «Скачать CSV» — потом пароли увидеть нельзя. Строки с ошибками пропускаются, их список показывается отдельно. За один файл — до 5000 человек.

Пароли хранятся как хеш. Сессия после входа живёт в cookie 14 дней.

## Живой квиз

Ведущий проводит свой квиз в публичной комнате. Суперглавный, регион и организация проводят учебный квиз так, как описано выше: регион и организация только приватной комнатой для класса. На экране комнаты QR-код и ссылка. Телефоны должны быть в той же сети Wi‑Fi. Если сайт открыт как `localhost`, ссылка ведёт на адрес компьютера в сети и на тот же порт, что в адресной строке, например `http://192.168.0.101:5174/play/633592`.

Участник вводит имя и ждёт в лобби. Войти можно только до старта. «Начать игру» открывает первый вопрос. Пробел или стрелка вправо на экране ведущего делают то же, что большая кнопка. На телефонах варианты можно выбрать кнопками 1–4. После последнего вопроса — итог.

Очки считает сервер по времени прихода ответа.

- Верный и мгновенный ответ: 1000.
- Верный в конце таймера: 500.
- Между этими точками очки снижаются равномерно.
- Неверный ответ и молчание: 0.

Правильный вариант не отправляется на телефоны, пока вопрос не закрыт.

Правила квиза:

- Название: 2–80 символов.
- От 1 до 50 вопросов.
- Текст вопроса: 2–200 символов.
- 2–4 варианта, каждый до 80 символов. Пустые поля при сохранении отбрасываются.
- У вопроса один правильный ответ.
- Время на ответ: 10, 20, 30 или 60 секунд.
- В одной комнате до 300 участников.

В редакторе квиза «Загрузить Excel» читает `.xlsx`: каждая строка — вопрос, первый столбец — текст, следующие — варианты. Ячейку правильного ответа нужно залить любым цветом, кроме белого. Пустая заливка и белый цвет не считаются ответом. Если первая строка — заголовок «Вопрос» и в ней ничего не залито, она пропускается. После загрузки у каждого вопроса 20 секунд. «Скачать шаблон» отдаёт файл с заголовком и двумя примерами.

Комната хранится в Postgres и поднимается после перезапуска, пока не истекла. Комната живёт до 4 часов, экран итога — 30 минут. Живые комнаты рассчитаны на один экземпляр приложения: таймер держится в памяти процесса.

Ведущий управляет комнатой по секретному токену в `sessionStorage`, не по ссылке. В ссылке из QR только код комнаты.

## Настройки

Локально — файл `server/.env`. Для Docker — `.env` рядом с `docker-compose.yml` (образец `.env.example`).

```env
SESSION_SECRET=замените-на-длинную-случайную-строку
PORT=3001
POSTGRES_URL=postgresql://testonline:пароль@127.0.0.1:5432/testonline
PG_POOL_MAX=20
MEDIA_DIR=/var/lib/testonline/media
LESSON_MAX_ATTEMPTS=1
COOKIE_SECURE=1
```

- `POSTGRES_URL` — строка подключения к Postgres. Без неё сервер не стартует. Подойдёт и `DATABASE_URL`.
- `PORT` — порт процесса API. В разработке его не открывают: сайт на 5174. В Docker образ задаёт `PORT=3001`, Nginx ходит на `app:3001`.
- `PG_POOL_MAX` — размер пула соединений, по умолчанию 20. `PG_SSL=0` выключает TLS, когда Postgres рядом (docker compose, локальная сеть). Для `localhost` TLS и так не используется.
- `MEDIA_DIR` — папка картинок и видео.
- `COOKIE_SECURE=1` — когда сайт открыт по HTTPS.
- `TRUST_PROXY=1` — приложение за Nginx и читает адрес клиента из `X-Forwarded-For`.
- `MEDIA_ACCEL=1` — после проверки прав картинки и видео отдаёт Nginx через `X-Accel-Redirect` (нужен `location /media-internal/` в `deploy/nginx/default.conf`).
- `SUPER_LOGIN` и `SUPER_PASSWORD` — первый суперадминистратор, создаётся один раз при пустой базе.

## Сборка одним процессом

```bash
npm run build
npm run start --prefix server
```

Процесс отдаёт и API, и собранный сайт на `PORT` (по умолчанию 3001). Для обычной работы это не нужно: открывайте http://localhost:5174 через `npm run dev`.

## Запуск в Docker

Четыре контейнера: Nginx со статикой, приложение, Postgres и ежедневный бэкап.

```bash
cp .env.example .env
docker compose up -d --build
```

В `.env` заполните `SESSION_SECRET`, `POSTGRES_PASSWORD` и `SUPER_PASSWORD`. Сайт открывается на порту из `HTTP_PORT` (по умолчанию 80). Логи: `docker compose logs -f app`.

| Том | Содержимое |
| --- | --- |
| `pgdata` | База Postgres |
| `media` | Картинки слайдов (`files/`) и видео уроков |
| `backups` | Дампы `pg_dump`, по одному в сутки, хранятся `BACKUP_KEEP_DAYS` дней |

Резервная копия — тома `media` и `backups`. Восстановление базы: `docker compose exec -T postgres pg_restore -U testonline -d testonline --clean < файл.dump`.

Nginx раздаёт собранный клиент и проксирует `/api` и `/socket.io` в приложение. Картинки и видео приложение само не льёт: оно проверяет вход и права, отвечает `X-Accel-Redirect`, файл с тома `media` отдаёт Nginx (`MEDIA_ACCEL=1`). Без Nginx приложение отдаёт файлы само.

Обновление: `git pull && docker compose up -d --build`. Если одного процесса Node перестанет хватать, увеличьте `APP_REPLICAS` в `.env`. Сессии в cookie, попытки в Postgres, файлы в общем томе. Живые комнаты квизов рассчитаны на один экземпляр: таймер в памяти процесса.

HTTPS: положите сертификаты в `deploy/certs`, раскомментируйте блок `443` в `deploy/nginx/default.conf`, добавьте порт `443:443` и том `./deploy/certs:/etc/nginx/certs:ro` сервису `web`, поставьте `COOKIE_SECURE=1`.

## Проверки

```bash
npm test
```

Нужен доступный `POSTGRES_URL` (из окружения или `server/.env`). Каждый файл тестов пишет в свою схему Postgres и удаляет её в конце, общая база не затирается. `PG_SSL=0` для локального сервера без TLS.

Проверяются подсчёт очков, Excel, статистика квиза, ход комнаты, роли и уроки.

| `server/src/index.js` | HTTP API и Socket.io |
| `server/src/db.js` | Postgres |
| `server/src/admin.js` | Области, районы, организации, классы, люди, кому можно запустить квиз, статистика платформы |
| `server/src/lessons.js` | Уроки, медиа, проверка теста |
| `server/src/rooms.js` | Комната квиза, таймер, очки, приватный класс |
| `server/src/domain.js` | Правила квиза и формула очков |
| `server/src/excel.js` | Вопросы квиза из Excel |

Страницы:

| Адрес | Кто видит |
| --- | --- |
| `/` | Главная |
| `/login` | Вход |
| `/admin` | Состав: области, организации, классы, люди. Без результатов тестов |
| `/admin/stats` | Статистика. Суперглавный сначала видит области и открывает одну из них. Дальше, как и у администратора региона, карточки ведут на районы, организации, уроки и квизы этой области |
| `/admin/materials` | Уроки |
| `/admin/materials/quizzes` | Учебные квизы суперглавного и запуск классу |
| `/admin/regions` | Области |
| `/admin/staff` | Администраторы области или организации, в зависимости от роли |
| `/admin/organizations` | Организации своей области |
| `/admin/classes` | Классы своей организации |
| `/admin/learners` | Тестируемые |
| `/admin/quizzes` | Запуск учебного квиза: регион — по области, организация — у себя |
| `/learn` | Уроки тестируемого |
| `/learn/lessons/:id` | Урок и тест |
| `/host` | Сводка квизов ведущего |
| `/host/quizzes` | Квизы |
| `/host/history` | История игр |
| `/host/quiz/:id` | Редактор квиза |
| `/host/quiz/:id/stats` | Запуски квиза |
| `/host/room/:code` | Экран ведущего |
| `/play/:code` | Экран участника |
